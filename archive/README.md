# Archive Index

Эта папка содержит файлы, вынесенные из корня репозитория для упрощения рабочей структуры.

## Перенесенные файлы
- `AGENTS.md` — старые операционные заметки.
- `KNOWN_ISSUES.md` — временный список проблем/черновик.
- `OPERATIONS.md` — служебные эксплуатационные заметки.
- `PR_DESCRIPTION.md` — временное описание для PR.

## Политика архива
- Файлы не удаляются безвозвратно: сначала переносятся в `archive/`.
- Если файл снова потребуется в основном потоке, его можно вернуть в корень или в `docs/`.
